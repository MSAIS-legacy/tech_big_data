# Задание V

Вариант 26 среди 11 формул циклически даёт вариант 4. Для `N=1000` вычисляется та же двойная сумма, что в заданиях I и II. Последовательная версия сравнивается с запуском независимых вычислений через `Concurrency::task_group`. После `wait()` результаты сверяются. Размер последовательности можно передать первым аргументом для короткого пробного запуска.
