# Задание III

Из 12 вариантов вариант 26 циклически даёт вариант 2: `x_n = sin(n)`. По умолчанию создаются требуемые 50 000 000 элементов и сравниваются `std::sort`, `concurrency::parallel_sort` и `concurrency::parallel_buffered_sort`. После каждой сортировки проверяется упорядоченность и совпадение контрольной суммы. Для быстрого пробного запуска размер можно передать первым аргументом.
