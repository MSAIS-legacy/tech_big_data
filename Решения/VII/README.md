# Задание VII

Из 15 вариантов вариант 26 циклически соответствует варианту 11:

`f(x,y) = exp(-sqrt(abs(x))) * product(k=0..infinity) cos(x / (sin(y)^2 + exp(sqrt(k))*cos(1/(k+1))))`.

Несобственный интеграл заменён интегралом на `[0, upper]`, а произведение — конечным произведением. Значения по умолчанию: `y=1`, `N=200000` интервалов Симпсона, `upper=200`, 512 членов произведения. Их можно изменить аргументами `y N upper product_terms`. Сравниваются обычная формула Симпсона и версия на `concurrency::combinable`; результаты проверяются с учётом накопления сумм в разном порядке.
