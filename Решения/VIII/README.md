# Задание VIII

В конвейерной части условия определены 12 вариантов пар `f1`, `f2`; циклический вариант 26 равен 2. Формулы:

- `f1(x) = sum (x+n)/(1+abs(x)+n^3+k^2+j^2)`;
- `f2(x) = sum x/(1+abs(x)+(n^2+j^2)^(3/2)+k^3)`;
- все три индекса меняются от 0 до `N` включительно, итог `y=f2(f1(x))`.

Реализованы последовательная версия, конвейер из блоков сообщений с двумя программными агентами и конвейер из двух `concurrency::transformer`. Сообщения содержат исходный индекс, поэтому результат корректно восстанавливается даже при изменении порядка. По умолчанию взяты параметры исходного примера `N=100`, 1000 входных значений; для быстрого запуска можно передать `terms count`.

Формулы 14–26 на последней странице `VIII.pdf` описывают `f(x,y)` для интегральной задачи, не задают композицию `f2(f1(x))` и к вариантам конвейера не относятся.
