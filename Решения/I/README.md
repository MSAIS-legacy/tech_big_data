# Задание I

Выполнены обе части файла `I.pdf`.

- Для 11 формул вариант 26 циклически даёт вариант 4.
- Формула: сумма по `k,j=1..max(20,floor(20*abs(x)))` от `x^2*k*cos((k+j)*x)/(x^2+k^3+j^2)`.
- Первая часть сравнивает обычный цикл и `concurrency::parallel_for` для 2000 значений.
- Во второй части вариант контейнера 26 среди трёх вариантов равен 2, поэтому используется `std::deque`; сравниваются `std::for_each` и `concurrency::parallel_for_each`.
- После каждого теста выполняется численная сверка результатов.
