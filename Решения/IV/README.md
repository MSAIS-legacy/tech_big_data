# Задание IV

Из 12 вариантов вариант 26 циклически соответствует варианту 2. На сетке `400 x 400` вычисляются функция

`sum cos(kx) sin(jy) / ((1+k^3+j^3) sqrt(1+k+j))`, `k,j=1..50`,

и её аналитическая производная по `y`. Сохраняются точки, для которых `df/dy <= 0`. Реализованы последовательный эталон и обе указанные потокобезопасные структуры: `concurrency::concurrent_vector` и `concurrency::concurrent_queue`. Сверяются число точек и контрольная сумма значений.
