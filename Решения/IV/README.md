# Задание IV

В обновлённом условии требуется отсортировать последовательность из N = 50 000 000 целых чисел и сравнить четыре алгоритма:

- `std::sort`;
- `concurrency::parallel_sort`;
- `concurrency::parallel_buffered_sort`;
- `concurrency::parallel_radixsort`.

В условии приведено 12 формул. Вариант 26 циклически соответствует формуле 2:

x_n = 4 · 10^9 · |sin(n)|,  n = 0, 1, ..., N - 1.

Значения хранятся в `std::vector<std::uint32_t>`: максимальное значение 4 · 10^9 помещается в беззнаковый 32-битный тип, но не помещается в знаковый `int32_t`. Преобразование из `double` в целый тип выполняется усечением дробной части, как в приложенном к заданию примере `parallel_radixsort.cpp`.

Исходная последовательность создаётся один раз. Перед каждым запуском она копируется в отдельный рабочий вектор, причём копирование не включается во время сортировки. После каждого алгоритма программа проверяет:

1. что результат отсортирован по возрастанию;
2. что контрольные значения суммы и XOR совпадают с исходной последовательностью.

По умолчанию используется заданное N = 50 000 000. Для быстрого пробного запуска размер можно передать первым аргументом, например:

```text
task_IV.exe 1000000
```

Проект рассчитан на MSVC под Windows, поскольку алгоритмы `concurrency::*` входят в Microsoft Parallel Patterns Library (PPL).
